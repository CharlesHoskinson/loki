# GPU-BESTPRACTICE: external practice for a Rust GPU backend (haiku-v1-5)

1. Feature matrix must be additive. Cargo unifies features across the dependency graph, so a feature added by one crate turns on for all. Keep GPU features additive and select device runtime at runtime or with compile-time guards that reject conflicts. Source: https://doc.rust-lang.org/cargo/reference/features.html . Background: https://github.com/rust-lang/cargo/issues/8458 . Loki already enforces the mutual exclusion at src/lib.rs L14-17. Resolver v2 is needed to avoid build-dependency unification; confirm loki-gpu's workspace uses resolver 2 (crates Cargo.toml line 2 of workspace, UNVERIFIED that it is applied to Loki root).
2. Sanitizer gates for native lifetime tests: NVIDIA Compute Sanitizer provides memcheck (out-of-bounds/misaligned access), racecheck (shared memory hazards), synccheck (invalid sync). Source: https://docs.nvidia.com/compute-sanitizer/ComputeSanitizer/ and https://docs.nvidia.com/cuda/compute-sanitizer/index.html . Use these on the runtime's native tests (PLAN.md P2 gate).
3. Sticky errors. Illegal-address faults are typically sticky: later runtime calls keep failing and the context is effectively unrecoverable without process restart. Source (non-authoritative forum evidence): https://forums.developer.nvidia.com/t/cuda-errors-determine-sticky-ness/271625 and https://github.com/NVIDIA/cuda-python/issues/2758 . Recommendation: poison the generation, treat as ContextLost, never publish output after uncertain completion (matches PLAN.md P2 kill criteria and loki-backend-api ErrorKind::ContextLost).
4. Asynchronous faults surface at later syncs or copies, so checked completion at every event join is required (TEST-PLAN.md "Async internals").
5. Determinism. Field arithmetic over BLS12-381 is integer-exact, so GPU equality with CPU is a bit-exact check; the risk is representation (Montgomery vs canonical) and ordering of MSM reduction, not floating point. No external source was consulted for MSM determinism; treat as design-derived (PLAN.md P6 requires deterministic reduction).
6. Licensing. sppark is Apache-2.0 per W4 notes (LOKI-GPU-MSM.md); keep NOTICE and PROVENANCE current (PLAN.md global constraints). Do not consult open-icicle source (prohibited).
