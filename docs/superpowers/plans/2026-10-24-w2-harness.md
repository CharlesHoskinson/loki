# W2 differential harness implementation plan

Goal: provide an independent correctness gate between the Loki path dependency
and the unmodified crates.io midnight-proofs 0.8.3 dependency.

Architecture: a macro expands one circuit/backend implementation against both
crate aliases. Only bytes and shared curve/field types cross the boundary.
The circuit fills 2^k - 32 rows with a nonlinear gate, copy permutation, public
input, 8-bit lookup, and challenge-dependent second-phase advice. A no-lookup
control isolates deterministic proof generation from randomized lookup ordering.

Constraints: own workspace; no parent library changes; four build jobs;
sequential proofs; k10/k14/k17 ordinary cases and ignored k20; no push.

- [x] Add manifest with distinct path/registry sources and first integration
  tests. Run dependency resolution and observe missing harness behavior.
- [x] Implement the shared circuit and backend, checked SRS/VK serialization,
  cross verification, negative proof/public-input controls, byte diagnostics,
  and benchmark timings. Verify k10 before larger proofs.
- [x] Add sequential gate/benchmark binaries and a five-minute run script.
  Verify the full release gate, JSON benchmark output, negative circuit
  controls, formatting, and dependency sources.
- [x] Document measurements, determinism limitations, unsafe test SRS, CUDA
  forwarding activation, and exact commands. Review, commit, and report on bus.

Validation: final reviewed k10/k14/k17 gate passed under the shared heavy lock
in 72.78s with 508002304 bytes peak RSS. k10 differential tests and mutation
controls passed; CUDA placeholder all-targets check passed. The trailing-byte
rejection regression was observed failing before the fix and passing after it.
The final source review found no remaining blockers. k20 and GPU execution were
not run. See the harness README for timing definitions, numbers and commands.

The gate reuses each proof pair for cross verification and determinism. Proof
inequality in the lookup fixture is diagnostic; inequality in the no-lookup
control fails. Verification/key/SRS mismatches always fail. CUDA initially is an
empty reserved feature, with the future loki/cuda forwarding line documented.
